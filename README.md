# 证据清单与证据材料编制

给办理中国民商事诉讼、仲裁案件的律师和团队使用的 Codex Skill。提供本案原始材料，说明代表哪一方、准备证明什么，就可以让 Codex 起草 Word 证据清单，按清单顺序编成 PDF 证据册。已有提交稿时，也可以只审核或只改指定材料。

## 能做什么

| 办案任务 | 具体处理 |
| --- | --- |
| 起草证据清单 | 优先沿用本案范本，逐项写清证据名称、来源、页数和证明目的。例如，签收单只记载收货，就写明谁在何时签收了哪台设备；质量验收另查依据。 |
| 编排证据材料 | 按清单顺序合并合同、回单、邮件和聊天记录，核对附件、签章页及长图接缝。可在右上角标“证2-3”，表示第2项证据的第3页。 |
| 修订已有卷册 | 首次提交前增删、调序后，同步核对清单、页角编号、证明目的中的引页和整册总页数。补充举证时保留已提交卷册的编号。 |
| 审核与打印 | 从清单定位到原件，再从成册页面反查来源。遇到打印时正文缺失，可另做兼容打印版并指出应试打的 PDF 页位。 |

## 怎么安装

**直接让 Codex 安装。** 把下面这句话复制到 Codex 对话中：

> 请从 https://github.com/FakeChenMing/prepare-evidence-bundle 安装个人 Skill。技能文件 SKILL.md 在仓库根目录，安装目录名用 prepare-evidence-bundle。安装后请核对文件，并告诉我怎么调用。

**也可以手动安装。** 在本仓库点击 **Code → Download ZIP**，解压后，将含有 `SKILL.md` 的文件夹改名为 `prepare-evidence-bundle`，放进 Codex 的个人技能目录。默认安装后的文件位置如下：

- macOS / Linux：`~/.codex/skills/prepare-evidence-bundle/SKILL.md`
- Windows：`%USERPROFILE%\.codex\skills\prepare-evidence-bundle\SKILL.md`

如果设置了 `CODEX_HOME`，就使用该目录下的 `skills` 文件夹。安装后新开一个 Codex 对话，输入 `$prepare-evidence-bundle` 并选择同名技能即可调用。

## 怎么用

让 Codex 打开本案材料所在的文件夹，或在对话中附上材料。说明**代表哪一方、这次要交付什么、哪一版是修改底稿**。有法院、仲裁机构或团队指定的范本时一并提供。以下示例可以直接复制，再替换成本案情况。

**第一次制作清单和证据册**

> 使用 $prepare-evidence-bundle。我方是出租人。请根据文件夹中的租赁合同、签收单、发票和银行回单，制作 Word 证据清单和配套 PDF 证据册。分别核对租金和保证金。无法从回单确认用途的款项列入内部待核说明。

**只审核，先保留现有版本**

> 使用 $prepare-evidence-bundle。请核对这份清单和证据册，重点检查证明目的是否有原件支持、引页能否找到对应内容。请按“证据序号、PDF 页位、发现的问题、建议修改”列出结果，这一步只审核。

**首次提交前换页**

> 使用 $prepare-evidence-bundle。这一版尚未提交。请用附件中的完整签章件替换证据2，沿用现有顺序和页角编号样式，另存新版清单和证据册。请核对替换后受影响的引页，并分别报告材料页数和含清单在内的 PDF 总页数。

## 使用条件

仓库提供的是编制流程，完整规则见 [SKILL.md](./SKILL.md)。生成 Word、合并或逐页检查 PDF，需要当前 Codex 环境具备相应的文件处理能力；识别扫描文字、开展实质证据评价或核验法源时，按需配置 OCR、配套法律技能或法律数据库。实体打印效果以实际试打为准。案件材料请放在自己的办案工作区，公开仓库仅用于分享这套方法。
